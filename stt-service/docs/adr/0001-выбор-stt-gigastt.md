# ADR-0001: Выбор STT — GigaSTT

**Статус:** Accepted
**Дата:** 2026-10-28

## Контекст

Необходимо выбрать STT-модель для русскоязычного голосового ассистента. Первый этап — локальная проверка работоспособности.

## Решение

Выбран `gigastt` (GigaAM v3) как наиболее зрелая открытая модель для русского языка.

## Альтернативы

| Модель | Статус |
|--------|--------|
| T-one (Т-Банк) | Требует отдельного рассмотрения API/лицензии |
| whisper | Медленнее на CPU, хуже для русского языка |
| Silero STT | Требует юридического одобрения для коммерческого использования |

## Последствия

- Stage 1 фокусируется только на `gigastt`
- Сравнение с другими моделями — на Stage 2
- Используется offline-бандл v2.22.0 с GitHub Releases (публичный, MIT)
- Модель загружается из volume `gigastt-models` в Docker контейнере

## Метрики (Stage 1)

| Метрика | Значение |
|---------|----------|
