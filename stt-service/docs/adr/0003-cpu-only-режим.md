# ADR-0003: CPU-only режим

**Статус:** Accepted
**Дата:** 2026-10-28

## Контекст

Продакшен-GPU занята LLM-сервисом.

## Решение

Все STT/TTS тесты и финальное развёртывание — на CPU.

## Альтернативы

| Вариант | Статус |
|---------|--------|
| Выделить GPU под STT | Невозможно из-за нагрузки на LLM |
| Использовать облачный STT | Нарушает требование локальности |

## Последствия

- Приоритет моделям с хорошей производительностью на CPU (RTF < 1.0)
- GigaSTT показывает RTF 0.226 (0.226 с на 1-сек клип; датасет фиксированной длины, RTF = latency). Для длинных фраз TTFT ≈ длина + 700 мс (ADR-0016)
- T-one показывает CPU/Wall ratio ~5.0 (многопоточность ONNX Runtime)
