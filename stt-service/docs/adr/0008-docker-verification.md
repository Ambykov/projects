# ADR-0008: Docker verification — 8 блоков A–H

**Статус:** Accepted
**Дата:** 2026-10-29

## Контекст

Необходимо подтвердить, что STT Gateway работает корректно в Docker-окружении перед переходом к Фазе B.

## Решение

Проведён полный прогон 8 блоков тестов:

| Блок | Описание | Результат |
|------|----------|-----------|
| A | Регресс-бенчмарк (144 файла) | PASS, WER 2.08% |
| B | Случайные тройки (20 троек) | PASS, 19/20 (known limitations: иди, включи, вниз; критерий статистический — ADR-0010) |
| C | Edge cases протокола | PASS, 8/8 |
| D | Auth-тесты | PASS, 7/7 |
| E4 | Backpressure (21-я сессия) | PASS, 4429 |
| F | Метрики Prometheus | PASS |
| G | Bad audio тесты | PASS, 5/5 |
| H | Long utterance (4 сек) | PASS, 2 partials @ 107ms |

## Ключевые метрики

| Метрика | Значение |
|---------|----------|
| WER (Block A) | 2.08% |
| TTFP median | 125ms |
| TTFP на длинной (4 сек) | 107ms |
| Partials на длинной | 2 |

## Последствия

- Stage 4.A завершён
- Готово к переходу к Stage 4.B (HTML-страница с микрофоном)
