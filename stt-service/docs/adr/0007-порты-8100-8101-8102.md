# ADR-0007: Порты STT Gateway

**Статус:** Accepted
**Дата:** 2026-10-29

## Контекст

Несколько тестовых скриптов и документации используют разные порты, что вызывает путаницу.

## Решение

| Порт | Назначение |
|------|------------|
| 8100 | Production (docker-compose.yml, uvicorn по умолчанию) |
| 8101 | Test only — AUTH_MODE=none для D7 тестов (docker-compose.test.yml) |
| 8102 | Deprecated — не используется (был временным в ранних тестах) |

## Использование

```bash
# Production: Docker Compose (только 2 контейнера)
docker compose up -d
# → gigastt:9876, stt-gateway:8100

# Production: локальный uvicorn
uvicorn app.main:app --host 0.0.0.0 --port 8100

# Test: добавить stt-gateway-none на порту 8101
docker compose -f docker-compose.yml -f docker-compose.test.yml up -d
# → gigastt:9876, stt-gateway:8100, stt-gateway-none:8101

# Тесты используют 8100 по умолчанию
python3 scripts/test_suite_stage4a.py

# Тесты на другом порту (любой свободный, например 8101)
GATEWAY_PORT=8101 python3 scripts/test_suite_stage4a.py
```

## Последствия

- Все тестовые скрипты используют переменную окружения `GATEWAY_PORT` с default 8100
- stt-gateway-none вынесен из prod в отдельный docker-compose.test.yml
