# ADR-0004: Формат аудио для тестов

**Статус:** Accepted
**Дата:** 2026-10-28

## Контекст

Необходимо единое представление аудио для сравнения моделей.

## Решение

WAV, PCM16, mono, 16 kHz.

## Альтернативы

| Формат | Причина отказа |
|--------|----------------|
| MP3 | Потери качества, лишняя декодировка |
| 44.1 kHz | Избыточно для речи, больше RAM |

## Последствия

- Все тестовые файлы приводятся к этому формату через `scripts/convert-audio.sh`
- GigaSTT ожидает 16 kHz — при отправке 48 kHz распознавание некорректное
- SDK должен ресемплировать 48→16 кГц перед отправкой через шлюз
